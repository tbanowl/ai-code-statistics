# Refactor Tasks

重构定时任务以及统计表结构，时间字段都使用时间戳，精确到毫秒。

## 新的统计逻辑

### 每日统计任务

以天、仓库、代码贡献者为维度统计代码量、提交次数、代码行数等指标。
统计的代码可以传入仓库、贡献者、开始日期和结束日期，如果没有传入，则默认统计当天的数据。
统计时同时将仓库和贡献者信息，以及关系记录到数据库中。

### 表的大概结构

每张表都有以下字段：

- ID，使用 XID 生成
- 创建时间，时间戳
- 更新时间，时间戳

#### 每日统计表

- AI 代码生成量，根据 check_point 事件中 `kind` 字段值为 `ai_agent` 的记录统计
- AI 代码采纳量，根据 commited 事件统计 
- 人类代码量，根据 commited 事件统计
- AI 代码占比，公示：AI 代码采纳量 / （人类代码量 + AI 代码采纳量）
- 当天日期
- 仓库 ID
- 仓库名
- 贡献者姓名
- 贡献者 ID
- git_ai_version

#### 仓库表

字段：

- 仓库地址
- 仓库名，截除 http 或 ssh 的 域名得到仓库名

#### 贡献者表

字段：

- 贡献者姓名
- 贡献者 ID

#### 仓库贡献者关系表

字段：

- 仓库 ID
- 贡献者 ID

### 接口

- 仓库分页接口,支持按照仓库名、日期范围等条件查询
- 贡献者分页接口,支持按照贡献者姓名、日期范围等条件查询
- 统计数据查询接口，支持按照仓库、贡献者、日期范围等条件
- 手动触发统计任务，接口参数包括仓库、贡献者、开始日期和结束日期。 

## UI 展示

首页展示统计数据的报表，包括 AI 代码生成量、AI 代码采纳量、人类代码量、AI 代码占比等指标的趋势图和分布图。并且可根据仓库、贡献者等维度进行筛选和对比分析。默认查询最近 7 天的数据。

支持页面上触发统计任务，用户可以选择仓库、贡献者、开始日期和结束日期来执行统计任务。
